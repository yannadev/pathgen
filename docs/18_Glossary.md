# 18 — Glossary

---

## A

### Advance
Q-learning action. Student has mastered the lesson, move to next lesson.

### Activity
Mixed-media assessment covering two consecutive lessons. Includes text, image, and video questions. Triggers BKT update for both lessons and a Q-learning decision.

### Activity Log
Admin page showing all admin actions (audit_log table).

### Adaptive Decision
The action chosen by Q-learning after a session: advance, review, or retake.

### Admin
System operator role. Manages accounts, classes, overrides. Cannot edit content or adaptive decisions.

### Admin Override
Special admin action: reset pretest, force posttest, or extend time.

### AI Feedback
Text generated by RAG, stored in `ai_feedback` column. Shows on result pages.

### Audit Log
Append-only table recording every admin action.

---

## B

### BKT (Bayesian Knowledge Tracing)
Estimates probability (p_known) that a student has mastered a lesson. Updates after every exercise and activity.

### bkt_mastery
Table storing per-student, per-lesson mastery probability.

### bkt_model_parameters
Table storing global BKT parameters: p_learn, p_slip, p_guess.

### Build RAG Index
Management command: chunks lessons, embeds them, writes lesson_embeddings.json.

---

## C

### Chunk
A piece of lesson content (300-500 tokens) used for RAG retrieval.

### Chunker
Function that splits lesson content into chunks. Structure-aware — never splits worked examples.

### Class
A group of students assigned to one teacher.

### class_students
Join table linking students to classes.

### Completion Page
Shows learning gain (posttest score minus pretest score).

### Content
Lessons, assessment questions, exercise questions, activities. Read-only at runtime.

### Cosine Similarity
Math function measuring similarity between two vectors. Used for RAG retrieval.

---

## D

### Deactivate
Soft delete — sets is_active = FALSE. Data preserved. User cannot log in.

### Deleted_at
Timestamp when an account or class was soft-deleted.

---

## E

### Embedding
A vector (list of numbers) representing the meaning of text. 1536 dimensions from OpenAI text-embedding-3-small.

### Empty State
"Chill lang, just chill." message shown when content/data is missing.

### Exercise
Short text-only MCQ quiz after a lesson. Triggers BKT update and Q-learning decision.

### exercise_q_decisions
Table storing Q-learning decisions from exercise sessions.

### Extend Time
Admin action adding minutes to an active pretest/posttest session.

---

## F

### FK RESTRICT
Database constraint preventing deletion of rows referenced by other tables. Protects research data.

### Force Posttest
Admin action granting early posttest access to a specific student.

### Frozen Snapshot
Values stored at decision time that cannot be reconstructed later. Thesis receipts.

---

## G

### Groq
External API for text generation. Model: gpt-oss-120b. Used for AI feedback.

---

## H

### Heartbeat
JavaScript ping every 30-60 seconds to track active session time.

### Hint
Text shown on retake for questions previously answered wrong.

### hint_used
Boolean in exercise_responses tracking whether hint was shown.

---

## I

### Idempotent
Operation that can be run multiple times without creating duplicates. Used in seed_content.

### is_active
Boolean flag for soft delete. FALSE = deactivated.

---

## J

### Just Chill
Page shown when student logs in but is not yet assigned to a class.

### JSON Storage
RAG embeddings stored as JSON file, not in a vector database.

---

## L

### Learning Gain
Posttest score minus pretest score. The thesis result.

### Lesson
Content unit with structured blocks (headings, paragraphs, examples, images).

### lesson_embeddings.json
Generated JSON file storing chunk vectors for RAG retrieval.

### lesson_progress
Table storing per-student, per-lesson status.

### Lesson Path
Page showing fixed lesson sequence with student's current position.

---

## M

### Mastery
Probability (0-1) that student knows a lesson. Stored in bkt_mastery.

### Modal
Popup overlay on top of current page for confirmation or input.

---

## O

### Orchestrator
Function coordinating the session completion flow: Grade → BKT → Q-learning → Apply action → RAG feedback.

### Override
Admin action: reset pretest, force posttest, extend time.

---

## P

### p_guess
BKT parameter: probability of correct answer despite not knowing (0.25 for 4-choice MCQ).

### p_known
Current mastery probability for a student-lesson pair.

### p_learn
BKT parameter: probability of learning per practice opportunity.

### p_slip
BKT parameter: probability of wrong answer despite knowing.

### password_must_change
Boolean forcing password change after admin reset.

### Posttest
Final assessment. Same question bank as pretest. Measures learning gain.

### Pretest
Baseline assessment. Initializes BKT per lesson.

### Prerequisite Chain
Fixed lesson order. Lesson N requires completion of lessons 1 to N-1.

---

## Q

### Q-learning
Decision module choosing advance, review, or retake after each session.

### Q-table
Maps states (mastery × attempts) to action values. Stored as JSON.

### q_decisions
Tables storing Q-learning decisions with frozen snapshots.

---

## R

### RAG (Retrieval-Augmented Generation)
Pipeline that retrieves relevant lesson chunks and generates grounded feedback.

### Reset Content
Management command wiping content tables.

### Reset Pretest
Admin action wiping student progress, restarting from pretest.

### Retake
Q-learning action. Student retries exercise with hints for previously wrong questions.

### Review
Q-learning action. Student re-reads the lesson.

### Role
User type: admin, teacher, or student.

---

## S

### Seed Content
Management command loading content from JSON files into database.

### Short Exercise
Text-only MCQ quiz for a lesson.

### Soft Delete
Deactivation instead of deletion. Data preserved.

### State Table
Table storing current state (e.g., student_progress, lesson_progress).

### Structure-Aware Chunking
Chunking that respects content blocks and never splits worked examples.

### student_progress
Table storing current position and status per student.

### Study Time
Active time tracked via heartbeats, stored in session tables.

---

## T

### Temp Password
Default password assigned by admin. Forces change on first login.

### Three-Pillar Architecture
BKT (estimate), Q-learning (decide), RAG (feedback). Independently measurable.

---

## U

### update_or_create
Django ORM method for idempotent seeding.

---

## V

### Vector
List of numbers representing text meaning. 1536 dimensions.

### Video Checkpoint
Point in activity video where it pauses and shows a question.

---

## W

### Whitenoise
Library serving static files in production without nginx.

---

## Z

### (No terms)
