LESSON 1: OPERATIONS ON INTEGERS

CONTENT:

I. Introduction to Integers
Integers are the set of whole numbers and their opposites. They include positive numbers, negative numbers, and zero.
Set of Integers: { ..., -3, -2, -1, 0, 1, 2, 3, ... }
- Positive Integers: Numbers greater than zero (1, 2, 3, ...)
- Negative Integers: Numbers less than zero (-1, -2, -3, ...)
- Zero: Neither positive nor negative

II. Absolute Value
The absolute value of a number is its distance from zero on the number line. Distance is always positive or zero.
Symbol: |a|
Rules:
- |5| = 5
- |-5| = 5
- |0| = 0
Key Concept: Absolute value is always non-negative.

III. Addition of Integers
Rule 1: Same Signs
Add the absolute values and keep the common sign.
Examples:
- (+5) + (+3) = +8
- (-5) + (-3) = -8

Rule 2: Different Signs
Subtract the smaller absolute value from the larger absolute value. Keep the sign of the number with the larger absolute value.
Examples:
- (-8) + (+5) = -3
- (+8) + (-5) = +3

IV. Subtraction of Integers
Key Rule: To subtract an integer, add its opposite.
a - b = a + (-b)
Examples:
- 7 - 4 = 3
- 7 - (-4) = 11
- -7 - 4 = -11
- -7 - (-4) = -3
Common Mistake: Students often forget to change the sign when subtracting a negative.

V. Multiplication of Integers
Sign Pattern:
- Positive × Positive = Positive: (+3) × (+4) = +12
- Positive × Negative = Negative: (+3) × (-4) = -12
- Negative × Positive = Negative: (-3) × (+4) = -12
- Negative × Negative = Positive: (-3) × (-4) = +12
Summary: Same signs → Positive product. Different signs → Negative product.

VI. Division of Integers
Sign Pattern:
- Positive ÷ Positive = Positive: (+12) ÷ (+4) = +3
- Positive ÷ Negative = Negative: (+12) ÷ (-4) = -3
- Negative ÷ Positive = Negative: (-12) ÷ (+4) = -3
- Negative ÷ Negative = Positive: (-12) ÷ (-4) = +3
Summary: Same signs → Positive quotient. Different signs → Negative quotient.

VII. Order of Operations with Integers (PEMDAS)
1. Parentheses
2. Exponents
3. Multiplication and Division (left to right)
4. Addition and Subtraction (left to right)
Example: 3 × (-2) + 8 ÷ (-4) = -6 + (-2) = -8

LESSON 2: OPERATIONS ON RATIONAL NUMBERS

CONTENT:

I. What are Rational Numbers?
A rational number is any number that can be expressed as a fraction a/b where a and b are integers and b ≠ 0.
Examples: 1/2, 3/4, -2/3, 0.25 (1/4), 0.333... (1/3)
Rational numbers include fractions, decimals (terminating and repeating), and integers.

II. Fractions: Definition and Parts
- Numerator: The top number (how many parts we have)
- Denominator: The bottom number (how many equal parts the whole is divided into)
Example: In 3/4, 3 is the numerator and 4 is the denominator.

III. Types of Fractions
- Proper Fraction: Numerator < Denominator (3/4)
- Improper Fraction: Numerator ≥ Denominator (5/4)
- Mixed Number: Whole number + proper fraction (1 ¼)
Converting Mixed to Improper: 1 ¾ = (1 × 4 + 3)/4 = 7/4

IV. Addition and Subtraction of Fractions
Step 1: Find the Least Common Denominator (LCD)
Step 2: Convert fractions to equivalent fractions with the LCD
Step 3: Add or subtract the numerators. Keep the denominator.
Example 1 (Same Denominator): 3/8 + 2/8 = 5/8
Example 2 (Different Denominators): 2/3 + 1/4 = 8/12 + 3/12 = 11/12
Example 3 (Subtraction): 7/10 - 2/5 = 7/10 - 4/10 = 3/10

V. Multiplication of Fractions
Rule: Multiply the numerators. Multiply the denominators. Simplify if possible.
Formula: a/b × c/d = (a×c)/(b×d)
Example 1: 2/3 × 4/5 = 8/15
Example 2 (With Negative): (-2/3) × (9/10) = -18/30 = -3/5
Example 3 (Mixed Numbers): 1 ½ × 2 ⅓ = 3/2 × 7/3 = 21/6 = 7/2 = 3 ½

VI. Division of Fractions
Rule: To divide by a fraction, multiply by its reciprocal.
Reciprocal: Flip the numerator and denominator.
Formula: a/b ÷ c/d = a/b × d/c
Example 1: 3/4 ÷ 2/5 = 3/4 × 5/2 = 15/8
Example 2: 5/8 ÷ 3/4 = 5/8 × 4/3 = 20/24 = 5/6

VII. Converting Between Fractions and Decimals
Fraction to Decimal: Divide numerator by denominator.
- 1/2 = 0.5
- 3/4 = 0.75
Decimal to Fraction:
- 0.5 = 5/10 = 1/2
- 0.75 = 75/100 = 3/4
Repeating Decimals:
- 0.333... = 1/3
- 0.666... = 2/3

LESSON 3: ALGEBRAIC EXPRESSIONS

CONTENT:

I. What is an Algebraic Expression?
An algebraic expression is a combination of numbers, variables, and operation symbols. It does NOT contain an equal sign.
Examples: 3x + 2, 5a - 7b, 2x² + 4x - 1

II. Parts of an Algebraic Expression
- Variable: A letter representing an unknown number (x)
- Coefficient: The number multiplied by the variable (3 in 3x²)
- Constant: A term without a variable (-5)
- Term: A part of an expression separated by + or -

III. Translating Verbal Phrases to Algebraic Expressions
- a number x increased by 5 → x + 5
- a number x decreased by 3 → x - 3
- twice a number x → 2x
- half of a number x → x/2
- three times a number x plus 4 → 3x + 4
- five less than twice a number x → 2x - 5
- a number x more than 8 → x + 8
Common Mistakes:
- "Less than" reverses order: "5 less than x" is x - 5, NOT 5 - x.
- "More than" adds: "5 more than x" is x + 5.

IV. Evaluating Algebraic Expressions
Substitute the given value(s) for the variable(s), then follow PEMDAS.
Example 1: Evaluate 2x + 9 when x = 5 → 2(5) + 9 = 19
Example 2: Evaluate 3x² - 2x + 1 when x = 2 → 3(4) - 4 + 1 = 9
Example 3: Evaluate 14 - 5x when x = 2 → 14 - 10 = 4

V. Simplifying Algebraic Expressions (Combining Like Terms)
Like terms = same variable raised to same power.
- 3x and 5x are like terms.
- 2x² and 4x² are like terms.
- 3x and 3x² are NOT like terms.
Example 1: 3x + 5x = 8x
Example 2: 7x² + 3x - 2x² - x = 5x² + 2x
Example 3: x² + 3x - 8x - 3x² = -2x² - 5x

VI. Multiplying Binomials (FOIL Method)
FOIL = First, Outer, Inner, Last
Example: (x - 3)(x - 2)
- F: x × x = x²
- O: x × (-2) = -2x
- I: (-3) × x = -3x
- L: (-3) × (-2) = +6
- Sum: x² - 2x - 3x + 6 = x² - 5x + 6

LESSON 4: WORD PROBLEMS

CONTENT:

I. Key Words and Their Mathematical Symbols
- sum, added to, more than, increased by → +
- difference, subtracted from, less than, decreased by → -
- product, times, multiplied by, twice → ×
- quotient, divided by, ratio → ÷
- is, equals, was, became → =

II. Translating Word Problems into Equations
Step 1: Read the problem carefully.
Step 2: Identify the unknown and assign a variable (usually x).
Step 3: Translate the words into a mathematical equation.
Step 4: Solve the equation.
Step 5: Check your answer.

III. Common Types of Word Problems

Type 1: One-Step Problems
Example: "Six more than a number x is 3."
Translation: x + 6 = 3
Solution: x = -3

Type 2: Age Problems
Example: "Jeff is 10 years old and his brother is 2 years old. In how many years will Jeff be twice as old?"
Let x = number of years
Jeff's age: 10 + x
Brother's age: 2 + x
Equation: 10 + x = 2(2 + x)
Solution: x = 6

Type 3: Number Problems
Example: "The larger of two numbers is 4 more than the smaller. Sum is 136."
Let x = smaller number
Larger = x + 4
Equation: x + (x + 4) = 136
Solution: x = 66

Type 4: Consecutive Integers
Example: "Sum of four consecutive integers is 86."
x + (x+1) + (x+2) + (x+3) = 86
Solution: x = 20
Note: Consecutive even integers differ by 2.

IV. Steps for Solving Word Problems
1. Read and underline important information
2. Identify unknown and assign variable
3. Write the equation
4. Solve
5. Check if answer makes sense
6. Write final answer in complete sentence

V. Common Mistakes to Avoid
1. Misreading operation — "less than" reverses order
2. Forgetting to combine like terms
3. Mixing up variables
4. Not checking the answer
5. Ignoring units
